# 剑网三副本管家 v2.2.10

## 新增需求

- **CD 概览支持按心法和账号筛选** - CD 概览表新增两个下拉筛选框：可以只看某个心法（如只看奶歌、气纯）的角色，也可以只看某个账号下的角色，两者可以同时使用。下拉里只会出现当前实际存在的心法和账号，不会列出没有角色的空选项；筛选后角色名前还会显示对应的职业图标，方便快速认号。筛选条件可以一键清除。
- **CD 概览可选择是否展示历史赛季周常** - 设置的「界面」分组新增「展示周常」开关。开启时保持现状：CD 概览会显示当前和历史赛季的全部周常副本；关闭后只显示当前赛季的副本，之前赛季的周常不再占用列宽（收藏过的历史赛季副本仍会出现在收藏列，不受影响）。
- **试炼之地简化装备确认流程** - 试炼记录不再有「确认本轮无装备」「已核对全部牌面」两个待确认状态：翻牌时选了哪个牌位、牌上有没有装备，记录里就直接呈现，不需要额外手动核对；概率统计也改为直接使用已确认牌位的记录，结果不受影响。补录翻牌时必须先选择翻到的牌位才能保存，未获得装备的翻牌不用填写任何装备信息。
- **副本管理可切换新版与旧版** - 设置里新增「副本管理」选项。默认的新版进入副本管理就是 CD 概览表，一眼看出各角色本周进度；切成旧版后恢复以前的样子，顶部重新出现「团队副本 / 试炼之地 / 百战」页签，团队副本页展示本周团队秘境与收藏副本卡片，习惯按副本整理的话可以沿用以前的操作方式。
- **旧版带回角色卡片上的账号与密码** - 切到旧版后，团队副本、试炼之地、百战的角色卡片底部重新显示账号、代清备注与密码，账号和密码都能一键复制，密码本身只显示为掩码。
- **系统配置分类更清晰** - 以前「游戏配置」和「自定义配置」两个分类里既有游戏设置，也有自动扫描、试炼截图识别、自动刷新装分这类应用自身行为，让人不清楚某个开关该去哪一页找；现在这两页合并成一页「游戏与应用」，内部按「游戏 / 应用行为 / 界面 / 数据与维护」分成四段，每段都有自己的标题和分隔区域，组内选项挨在一起、组与组之间留出明显间隔。
- **副本管理可自动隐藏非满级角色** - 设置的「界面」分组新增「自动隐藏非满级角色」开关（默认关闭）。开启后，副本管理（CD 概览表、团队副本、试炼之地、百战）只显示已达当前版本满级的角色，练级中的小号不再出现在列表里；角色等级在「角色分析」扫描时自动识别，开启开关前扫描过的老角色重新扫描一次即可补上等级。角色等级未知时仍会正常显示，不会被误隐藏。

## 修复 bug

- **删除过的试炼记录重新扫描可以找回** - 手动删除试炼记录后，此前再点「扫描本周」也不会重新扫出同一条记录，误删后无法恢复。现在手动扫描会重新导入已删除的试炼记录及其翻牌明细；后台自动扫描仍不会打扰已删除的记录。
- **试炼之地补扫覆盖上一个游戏周** - 打试炼之地时没开应用，此前「扫描本周」只能识别到本周一之后落盘的记录，跨周补扫会漏掉上周的通关记录。现在离线补扫会把范围放宽到上一个游戏周，上周打的试炼也能正常补进来。
- **自动识别的试炼记录可以补录翻牌** - 自动识别的试炼记录如果没从日志里找到翻牌明细（例如打的时候没开应用），此前既没有补录入口，扫描也不认。现在记录列表会提示「补录翻牌」，点开后可在编辑弹窗里直接补记每次翻牌的牌位和装备，补录的翻牌同样计入概率统计。已由日志自动记录翻牌明细的记录仍保持逐笔修改方式，不会被误覆盖。
- **试炼翻牌截图在聊天日志迟到时不再丢失** - 剑网3聊天插件落盘有延迟（实测可超过 15 分钟），此前截图识别在等待期间因内存帧被清理而失效，导致翻牌装备识别不到。现在识别结果会先持久化保存，聊天日志晚到也能自动补录，最多支持 2 小时内的迟到回执。
- **修复带服务器后缀的角色名无法自动扫描** - 部分角色在茗伊装备库中名字带服务器后缀（如「发白少·梦江南」），导致自动扫描误判为「角色未登记」而整号跳过。现在会自动剥掉与服务器一致的后缀再匹配，该类角色恢复正常扫描。
- **修复试炼之地「待确认」点开错记录** - CD 概览里点试炼之地一列的「待确认」，此前打开的是团队副本的待确认记录，找不到要处理的试炼记录。现在会打开该角色的试炼记录列表，可直接在列表里选中并确认；百战一列也一并核对，不会再错开团队副本的记录。
- **修复团队副本「待确认」展示全部记录** - CD 概览里点某角色某副本一列的「待确认」，此前弹窗里列出所有角色所有副本的待确认记录，需要自己翻找目标。现在弹窗只显示该角色该副本的待确认记录，确认完即走；通过页头的「待确认」按钮打开时仍显示全部记录。
- **修复待确认记录弹窗出现「(0)」空列表** - 从 CD 概览点「待确认」格子时，如果范围内已经没有待处理记录，此前会弹出一个显示「待确认记录 (0)」的空弹窗；确认完范围内的记录后，弹窗也会停留在这个空状态，需要手动关闭。现在范围内没有待确认记录时不再弹窗，确认完成后弹窗自动关闭。
- **修复末尾 BOSS 打完有剧情时漏记击杀** - 部分副本的最后一个 BOSS（如洛阳之战史朝义）打完还有一段剧情演出，结算奖励来得比以前判定用的"战斗结束"更晚或有前后偏移，导致整场副本漏记击杀、工资算少。现在改用对 BOSS 的最后一次伤害作为识别起点，并放宽宝箱回执与奖励的匹配要求，该类场次能正确补记击杀，收入不再缺项。
