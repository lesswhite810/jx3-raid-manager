# 剑网三副本管家 v2.1.44

## 新增需求

- **收益记录区分已拒绝记录** - 在收益记录的"全部"页签中，已拒绝的自动扫描记录会以红色标签标注显示，不再隐藏；在"收入"和"支出"页签中不显示，也不计入总收入、总支出和净收入统计
- **确认自动扫描记录时增加 CD 冲突检测** - 确认自动扫描记录前，如果同一角色在同一 CD 周期内已存在该副本的手动记录，会弹出提醒，避免重复占用 CD
- **已拒绝记录支持再次接受** - 拒绝过的自动扫描记录可以重新接受确认，恢复参与 CD 计算

## 修复 bug

- **修复 10 人本已确认记录重复扫描** - 10 人普通副本确认后再次扫描仍会重复创建记录的问题已修复
- **修复自动扫描记录副本名不完整** - 自动扫描记录的副本名现在使用完整名称（如"10人普通阆风悬城"），解决副本详情中无法显示对应 CD 记录的问题
- **修复收益统计包含未确认记录** - 收益概览、收益分布图表和副本详情中的统计数据不再包含待确认和已拒绝的自动扫描记录
