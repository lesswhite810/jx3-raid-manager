# 剑网三副本管家 v2.2.12

## 新增需求

- **CD 概览表直接显示试炼进行中** - 此前角色正在打试炼之地时，只在扫描按钮旁的待办列表里提示，容易忽略。现在概览表的试炼之地列会用沉香褐色 + 旋转图标直接标出该角色「进行中·第N层第M关」，鼠标悬停可看详情；出翻牌结果后该标记自动消失，颜色恢复为常规翻牌进度。
- **具体赛季也能看 CD 概览表** - 此前表格只在「概览」里有，切到某个赛季后只剩一排副本卡片，想看这个赛季各角色清没清就得退回去翻。现在选定赛季后，标题下方多了一行「CD 概览 / 副本卡片」切换：默认显示该赛季的 CD 概览表，只列出这个赛季的副本，点列头能直接进副本详情；要启用/禁用副本时切到「副本卡片」，改完再切回来即可。被禁用的副本难度照旧跳过，底部会提示跳过了几个。概览表补上了加载中的占位，数字变化不再让整行跳动；副本卡片上把启停开关直接做了出来并常驻显示，不用再靠右键，删除也改成确认弹窗而不是直接弹提示。
- **收益记录直接显示击败的 BOSS** - 收益概览的「收益记录」里，此前每条记录只显示副本、角色和金额，看不出这一场究竟打掉了哪些 BOSS，事后核对只能去别处翻。现在每条记录会在金额左侧列出本场击败的 BOSS 名称，自动识别的记录和手工记录的都能看到；某个副本没有配置 BOSS 列表时不显示，列表里不会多出空标签。

## 修复 bug

- **修复角色未登记时「扫描本周」静默跳过** - 角色没有在角色管理里登记、或登记的区服与当前登录的区服不一致时，此前扫描只会提示「没有需要更新的副本或试炼记录」，看着像一切正常，实际这个账号一条都没扫，也查不出原因；现在会直接说出是哪个角色、当前登录的是哪个区服，并提示该去新增这个角色，还是把已有角色的区服改对。这类账号也不再被算作扫描成功，扫描完成的提示里能直接看到。
- **修复概览表里被禁用的角色仍显示「未清」** - 在副本详情里把某个角色的某个副本禁用后，此前 CD 概览表里这一格依旧显示「未清」，看着像还要去打；现在这一格显示为「—」，也不再计入该副本列的已清角色数，从详情页返回概览即可看到变化。
- **修复副本详情角色卡片缺少账号与密码** - 从 CD 概览表点进副本详情后，角色卡片上此前只显示代清备注，看不到账号与密码，上号时还得回账号管理里翻。现在卡片底部恢复显示账号、代清备注与密码，账号和密码都能一键复制，密码本身仍只显示为掩码。
- **修复刷新装分后数值与当前穿戴对不上** - 游戏里的装分有两套口径：一套按当前穿戴的每件装备分别计算再累加，一套是角色面板分（额外含马具等加成），两者通常差几百。此前「刷新装分」一律取面板分，一旦换过马具或面板数据还没落盘，刷新出来的数值就和你身上实际穿的装备对不上，也没法逐件核对；现在优先按当前穿戴套装统计，查不到该角色时才退回原来的口径。到导入角色窗口点一次刷新即可看到变化。
