# 剑网三副本管家 v2.2.12

## 新增需求

- **CD 概览表显示试炼进行中** - 角色正在打试炼之地时，概览表中直接标出「进行中」状态；出翻牌结果后自动恢复为常规进度显示。
- **赛季页也能看 CD 概览表** - 选定某个赛季后，可在「CD 概览 / 副本卡片」之间切换：看进度用概览表，启停副本用卡片。
- **收益记录显示击败的 BOSS** - 每条收益记录旁列出本场击败的 BOSS 名称，事后核对不用再翻别处。

## 修复 bug

- **修复未登记角色扫描时被静默跳过** - 角色没登记或区服不一致时，此前扫描看似成功实际一条没扫；现在会明确说出原因和该怎么做。
- **修复被禁用角色仍显示「未清」** - 禁用后概览表该格显示「—」，不再误导还要去打。
- **修复副本详情角色卡片缺少账号密码** - 卡片恢复显示账号、密码与代清备注，均可一键复制。
- **修复刷新装分与实际穿戴不符** - 优先按当前穿戴的装备统计，数值和身上穿的能对上。
