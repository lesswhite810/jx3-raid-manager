# 剑网三副本管家 v2.1.47

## 新增需求

- **🎯 稀有掉落类型筛选** - 稀有掉落统计页新增按类型（玄晶/马具/宠物/挂件/坐骑/外观/称号/秘籍/其他）多选筛选，点击标签即可筛选，方便快速定位特定掉落
- **📋 活跃检测优化** - 切换角色后能更准确地识别当前在线角色，不再因茗伊插件后台写入导致已退出角色误判为在线

## 修复 bug

- **👥 同账号多角色 CD 冲突** - 修复同一账号下两个角色打同一个副本时，后一个角色的扫描被前一个角色手工记录拦截的问题（剑网三 CD 按角色独立，非按账号）
- **🗡️ 无 BOSS 配置副本跳过** - 修复无 BOSS 配置的小副本（如试炼之地）被错误注入击杀 BOSS 名的问题
- **📊 掉落实时扫描虚高** - 修复 chatlog 时间窗口跨副本污染导致的掉落数量虚高问题
- **🔄 CD 窗口跨难度匹配** - 修复同一副本不同难度（10人/25人普通/英雄）在同一 CD 窗口内互相错误匹配的问题
