# 剑网三副本管家 v2.1.53

## 新增需求

- **新增散件老板功能** - 在"待确认"面板中可以勾选"我是散件老板"，应用会自动识别本局副本散件（白名单材料 + 0 金装备）并计算散件估价，无需手动逐条挑选。估价会单独展示在结算详情中，便于核对实际收入
- **自定义标题栏与散件 UI 优化** - 窗口顶部控制按钮替换为应用自定义标题栏，整体视觉更统一；新增记录弹窗打开时会锁定背景滚动，散件编辑区在"添加记录"和"待确认"面板中样式完全一致，避免双滚动条与重复操作

## 修复 bug

- **修复 v2.1.52 历史遗留记录复核失效** - 上一版本上线的"历史记录复核"功能由于时间字段类型不匹配，历史扫描出的副本记录始终无法进入复核流程，本版本修复后历史扫描的记录可以被正确复核
