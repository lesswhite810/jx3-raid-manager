# 剑网三副本管家 v2.2.9

## 新增需求

- **最小化不再直接藏进托盘** - 点最小化按钮只把窗口收进任务栏，和常见软件一致；程序仍在后台运行，点任务栏图标即可回来。
- **关闭按钮可选行为** - 点关闭时不再只有一种结果：首次会询问是「最小化到托盘」还是「直接退出」，勾选记住后下次直接按选择执行。
- **关闭行为可随时改回询问** - 设置里新增「关闭按钮」选项，可在每次询问、最小化到托盘、直接退出之间切换；想重新被询问时选「每次询问」即可。
- **托盘菜单退出入口** - 托盘图标右键菜单里保留「退出应用」，隐藏到托盘后也能从托盘彻底关闭程序。
- **团队副本新增 CD 概览表** - 本周团队秘境与收藏副本的清理情况现在能用一张表格一眼看全：每个角色在各副本属于未清、部分清、待确认还是已清直接用颜色标出，不必再逐个点进详情确认哪个号还没清 CD；表头还会显示该副本本周已经清掉的角色数。
- **概览视图只保留 CD 概览表** - 版本下拉里的「收藏」改名成「概览」，这一项下不再重复列一遍副本卡片，只保留 CD 概览表；想看某个赛季的副本卡片，切到对应赛季即可。
- **概览表的列顺序更好找了** - 副本列按赛季从新到旧排列，同一个副本先 10 人再 25 人、先普通再英雄；试炼之地与百战两列挪到副本列后面，操作列固定在最右边不跟着动。某个玩法当前没有角色参与时，那一列会整体隐藏，表格不会留一列空白。
- **CD 概览表新增试炼之地与百战进度** - 每个角色本周翻了几次牌、打了几次百战，现在和副本 CD 一样汇总在同一张表里，不用切页面挨个看。
- **表格里点一下就能到达其它页面** - 点「试炼之地」「百战」两个列头进入对应页面，点副本列头进入副本详情；页面左上角新增「← 返回概览」，随时可回到汇总表。
- **顶部页签已移除** - 副本管理不再有「团队副本 / 试炼之地 / 百战」页签，进来直接看到汇总表。
- **表格按装分排序** - 概览表在角色名右侧多了一列装分，整张表按装分从高到低排列，没填装分的角色排在最后；想看战力靠前的号先清哪个副本会更顺。
- **表格里直接处理待确认** - 哪一格显示「待确认」，点这一格就会打开待确认记录去确认，不用再滚回页面顶部找按钮。
- **没清就直接补记录，清过就直接看记录** - 表格里的格子和它的状态对应起来了：显示「未清」「部分清」的格子点一下直接弹出添加记录，角色、账号和副本都已经填好，补完即可；显示「已清」的格子点一下打开这个角色在该副本的记录明细，可以查看、编辑或删除。试炼之地和百战两列同理，点未清格子补录、点已清格子看明细。
- **表格里直接复制账号密码** - 表格每行末尾新增了操作列，点图标即可把账号或密码复制到剪贴板；账号没有配置密码时不会出现复制密码的图标。
- **问题反馈二维码放大更好扫** - 设置里「问题反馈」的 QQ 群二维码原来只有指甲盖大小，手机凑近才对得上焦。现在与「赞赏」面板一样铺满大半屏，点一下还能再放大全屏查看；群号与入群提示在同一块区域里，默认窗口大小下无需拖动滚动条。二维码本身也已换成最新的一张。
- **角色卡片上的账号密码复制入口移到概览表** - 副本详情、试炼之地、百战里的角色卡片，原来会把账号直接摊在卡面上，密码则永远显示一串圆点，既占地方又看不出什么。现在这三个页面的角色卡片上不再带账号密码按钮，复制入口统一放到团队副本页 CD 概览表的操作列，需要时在表格里点一下即可。

## 修复 bug

- 修复部分副本最后一个首领已击杀、记录却仍显示未通关的问题。个别首领的战斗结束后，游戏没有在战斗记录里留下「脱战」这一行（例如中途掉线、切场景，或首领分阶段战斗的机制），此前会被当成战斗还没结束，导致这一场的结算奖励无法用来补上击杀记录；现在这类记录也能正确识别。
- 修复试炼之地的战斗记录会被算进团队副本统计的问题。以前打试炼之地时，它的记录可能被当成团队副本来计时和判断，影响同一时间段内团队副本的进度与掉落归属；现在试炼之地只参与试炼之地自身的判定，不再混入团队副本。
- 修复试炼之地截图识别偶尔全部失效的问题。游戏聊天插件会把聊天记录攒一段时间才统一写入磁盘，以前必须等记录落盘后才能识别翻牌结果，攒得越久就越容易错过识别时机，导致整轮翻牌一张都识别不到；现在截图画面会当场留存，无论聊天记录什么时候写入磁盘，都能在它出现后自动补上翻牌结果，不再依赖落盘时机。
- 修复窗口最大化后从托盘恢复会变回默认大小的问题。以前把窗口最大化再收进托盘，点托盘图标调出来时窗口会缩回启动时的固定尺寸，需要每次手动再点一次最大化；现在恢复时会保持你离开时的最大化状态。
