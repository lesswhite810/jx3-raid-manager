# 剑网三副本管家 v2.1.51

## 修复 bug

- **修复无底薪时副本收入虚高** - 此前在团队未宣布"每人底薪"的情况下，自动扫描会把副本结束后团长发放的工资以及后续所有拍卖分成都累加成总收入，导致显示金额远高于实际工资（例如 300 金工资被算成 1306 金）。现在改为取最后一个战斗日志之后的第一条收入记录作为副本收入，更符合"工资只发一次"的实际情况
- **修复进入下一个副本后上一副本仍显示"进行中"** - 此前在同一账号连续打多个副本时，第一个副本若未全清 BOSS、JX3 仍未退出、角色仍在线，会一直保持"进行中"状态无法转为"待确认"。现在只要检测到角色已经开始打后续副本，上一个副本就会被判定为已结束并可确认
- **修复安装或迁移时数据库被误删** - 此前在首次安装或切换数据目录时，若目标目录已存在空数据库文件，可能被误判为"权威文件"并删除源数据库，导致已有记录丢失。现在改为仅在源文件与目标文件完全一致时才清理源文件，否则保留源文件作为备份，避免误删
