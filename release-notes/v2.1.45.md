# 剑网三副本管家 v2.1.45

## 新增需求

- **启动自动刷新装分** - 新增「启动刷新装分」配置项（默认开启），开启后每次启动应用时自动从茗伊插件数据库刷新已导入角色的装分，无需手动在导入角色窗口刷新，可在「配置」页面关闭
- **自动扫描记录备注优化** - 自动扫描记录的备注现在会根据掉落内容动态生成，显示「特殊掉落: XX | 购买装备: YY」格式，方便快速识别每条记录的关键掉落物（玄晶、坐骑、秘籍、宠物、马具、挂件、外观、称号等特殊物品会自动标注）
- **JCL 缓存清理** - 新增 JCL 缓存清理功能，可解决因旧版缓存数据导致的 BOSS 记录缺失问题。在「系统配置」→「当前版本」卡片上连续点击 7 次开启 Debug 模式后，可在「自定义配置」区域清理缓存
- **试炼之地记录时间筛选** - 试炼之地详情弹窗新增「本周」与「全部」切换，全部模式下支持分页加载避免大量记录卡顿

## 修复 bug

- **修复未配置 BOSS 的副本无法扫描记录** - 除阆风悬城等少数副本外，其余副本（如西津渡、冷龙峰等）因未在副本 BOSS 配置表中维护 BOSS 列表，自动扫描时所有战斗日志被误判为"小怪战斗"导致无法生成记录。现已优化判定逻辑：无 BOSS 配置时不再过滤，通过战斗信号正常识别击杀并产出扫描记录
- **修复副本收入误纳入家园活动收入** - 副本结束后后续的家园活动等无关收入记录不再被误计入副本收入统计
- **修复数据库空文件导致赛季显示一直加载中** - 当数据库文件损坏为空文件时，应用自动重新初始化数据库，避免赛季信息永久显示「加载中」
- **修复扫描后待确认记录弹窗闪烁消失** - 扫描完成后待确认记录面板短暂显示「(0)」后消失的问题已修复
- **修复可交易装备数先显示 0 再跳变** - 启动时并行加载装备数据，避免概览和试炼翻牌界面的可交易装备数先显示 0 再突然变化
- **增强 BOSS 击杀判定** - 优化 BOSS 击杀识别逻辑，修复部分 BOSS（如笑妆娘）因旧版缓存导致击杀记录缺失的问题
- **优化账号管理全选显示** - 无匹配账户时全选框置灰显示「全选 (0 个账户)」，交互更清晰
- **优化配置页面光标显示** - 修复配置页面等文本容器误显示输入光标的问题，不可编辑区域统一显示箭头光标
