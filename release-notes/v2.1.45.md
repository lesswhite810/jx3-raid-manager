# 剑网三副本管家 v2.1.45

## 新增需求

- **启动自动刷新装分** - 新增「启动刷新装分」配置项（默认开启），启动时自动从茗伊插件数据库刷新已导入角色装分，无需手动操作
- **自动扫描记录备注优化** - 自动扫描记录的备注根据掉落内容动态生成，显示「特殊掉落 | 购买装备」格式，方便快速识别关键掉落物
- **试炼之地记录时间筛选** - 试炼之地详情弹窗新增「本周」与「全部」切换，全部模式下分页加载避免卡顿

## 修复 bug

- **修复部分副本与 BOSS 无法扫描识别** - 修复未配置 BOSS 的副本（如西津渡、冷龙峰等）无法生成扫描记录，以及部分 BOSS 击杀记录缺失的问题
- **修复副本收入误纳入家园活动收入** - 副本结束后后续的家园活动等无关收入不再被误计入副本收入统计
- **修复数据库空文件导致赛季显示一直加载中** - 数据库文件损坏时自动重新初始化，避免赛季信息永久显示「加载中」
- **修复扫描后待确认记录弹窗闪烁消失** - 修复扫描完成后待确认记录面板短暂显示后消失的问题
- **修复可交易装备数先显示 0 再跳变** - 启动时并行加载装备数据，避免界面数字先显示 0 再突然变化
- **优化多处界面交互体验** - 优化账号管理全选显示与配置页面光标显示等交互细节
