# 剑网三副本管家 v2.1.43

## 新增需求

- **副本掉落自动扫描** - 游戏运行时自动扫描副本战斗日志和聊天记录，识别击败的 BOSS、掉落物品、金币收支，生成待确认记录，无需手动添加
- **待确认记录管理** - 自动扫描的记录可在"待确认"面板中查看，支持直接确认、编辑后确认或拒绝，确认后的记录与手动记录一样参与 CD 管理
- **待确认记录编辑 BOSS 进度** - 编辑确认时可修改击败的 BOSS 列表
- **手动扫描本周** - 支持"扫描本周"按钮，离线扫描本周一至下周一所有账号的副本数据
- **角色活跃检测** - 自动检测游戏运行状态，仅扫描在线角色的副本数据，减少不必要的扫描开销
- **启动引导** - 首次使用或未配置游戏目录时显示引导界面

## 修复 bug

- 修复有收藏筛选时切换赛季仍显示收藏列表的问题

## 优化

- 统一全应用 BOSS 选择按钮的视觉风格，选中态统一为绿色系
- 统一试炼之地记录界面的筛选标签、翻牌标记、装备选择卡片的视觉风格，去除多余的阴影和缩放动画效果
- 副本管理界面在线角色优先排序显示
- 账号管理改为弹窗编辑方式，导入本地角色时已导入角色禁用选择
