# 剑网三副本管家 v2.1.49

## 新增需求

- **🎯 切换数据目录时增加冲突提示** - 切换自定义数据目录或恢复默认目录时，如果目标目录已存在数据库文件，会弹窗提示用户选择处理方式：覆盖目标文件（用当前数据替换目标旧数据）或取消切换，避免误操作覆盖重要数据

## 修复 bug

- **🔧 修复安装版与便携版数据互相串走问题** - 此前同时安装了安装版和便携版时，后打开的版本会把先打开版本的数据库文件迁移到自己的目录，导致两边数据互相覆盖或丢失。现在安装版和便携版的配置文件完全独立，两个版本可以稳定共存，互不干扰
- **🔧 修复切换数据目录时覆盖标记被提前消费问题** - 此前用户确认覆盖目标目录已有数据库文件后，应用运行期间的其他内部调用会意外触发数据迁移，导致覆盖标记被清除、迁移在重启前提前执行。现在数据迁移仅在应用重启时执行一次，确保用户选择（覆盖或保留）在重启时正确生效
