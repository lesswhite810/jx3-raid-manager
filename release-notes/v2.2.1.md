# 剑网三副本管家 v2.2.1

## 新增需求

- **首页收益概览合并散件估价** - 原"总收入 + 散件估价"两格合并为"本期总收入"一格，主数字展示总收入（不含散件），副标签展示"散件估价"，切换本周/本赛季/全部时数值随周期同步刷新，一眼看清总账与散件账
- **收益概览详情展示散件副信息** - 总收入/总支出/净收入三张卡片下方追加"散件预估收益/散件支出/散件净收入"（仅散件老板视角），散件老板可在同一卡片内对照总账与散件账
- **散件白名单汇总** - 收益概览详情新增"散件白名单汇总"区块，按物品统计获取总数、出现副本数、平均每个副本数量，方便对比白名单材料的副本级收益
- **详情页内容分区改为 Tab 展示** - 收益概览详情将"收益汇总图表 / 散件白名单汇总 / 收益记录"整合为三个 Tab 页，试炼翻牌统计同样拆分为"位置明细 / Boss出装备统计"两个 Tab，页面更聚焦、滚动更短
- **散件支出按白名单购买价统计** - 散件老板记录的"散件支出"口径调整为白名单物品的实际购买花费合计（扫描时从"花费[..]购买了"消息提取金额并随记录持久化）；旧版记录无购买价数据时仍按副本总支出近似，重新扫描后自动精确化

## 修复 bug

- **修复周期切换偶发失效** - 移除赛季信息加载失败时"本赛季"被静默切回"本周"的兜底逻辑；统一赛季起始时间的解析（兼容秒/毫秒时间戳），避免出现"本周与本赛季数据相同"的假象
