# 剑网三副本管家 v2.2.3

## 修复 bug

- **修复大量界面元素缺少背景色与描边色的问题** - 概览的收益 / 支出数值块、副本详情、待确认记录、玄晶明细、试炼统计、角色记录等模块中，约 100 处按设计标注的淡色样式（背景、描边）此前并未真正生效，相关卡片、提示条与选中态显示为无色；现已按设计既定浓度正常显示
- **修复玄晶记录的高亮底色未显示** - 副本日志中含玄晶的记录会以浅琥珀色底色突出显示，此前因底色相互覆盖只有左侧琥珀色边条生效；现已恢复，三种主题下均正常
- **修正主题名称** - 设置中的「江湖纸笜」更正为「江湖纸笺」；默认主题此前在更新日志中写作「原版」，现统一为界面上实际显示的「经典」
- **统一跨角色设置同步模块的配色** - 该模块此前仍沿用旧配色标准，现与其余界面保持一致
- **修复连续打两个副本时前一个副本一直停在「进行中」** - 一个副本结束后进入下一个副本时（尤其是中途重启过游戏），前一个副本可能长时间无法转为「待确认」，最长要等 6 小时兜底；现在只要检测到已经开始打后续副本，前一个副本立即判定为已结束
- **修复相邻两条副本记录的掉落与收入重复** - 上一场景下，后一个副本的拍卖与工资结算会被同时写入两条记录，表现为两条记录的掉落清单完全相同、收入重复计入；现在按副本切换点划分结算归属，同一份结算只写入对应的那一条记录
