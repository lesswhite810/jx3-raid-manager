# 剑网三副本管家 v2.2.0

## ✨ 新增功能

- **界面主题一键切换** - 设置中可在「经典」「江湖纸笺」「暗色」三套主题间即时切换，偏好自动保存，重启后保持；默认经典风格，老用户零适应成本
- **全新视觉基调「江湖纸笺」** - 主操作色由靛蓝调整为沉香褐，整体氛围更沉稳克制，长时段挂机管理窗口不再刺眼
- **轻量阴影体系** - 卡片 / 弹窗 / 提示的阴影强度整体下调，配合新主色，观感从「科技产品」转向「客栈告示牌」
- **统一圆角规范** - 全应用圆角收口到统一档位，杜绝过去不同界面圆角忽大忽小的跳变
- **设置面板分类改造** - 设置弹窗改为「左侧分类导航 + 右侧内容面板」布局，主题外观、版本更新、游戏数据、高级、问题反馈五类入口一目了然，不用再翻长页面
- **收益记录分页加载** - 收益概览的记录列表默认展示最近 100 条，点击「加载更多」按需追加，无论积累多少条记录都保持流畅

## 🐛 问题修复

- **修复收益概览记录区双滚动条** - 此前页面和记录卡片各有一条滚动条，滚动容易混乱。现在整个收益概览只有一条滚动条，标题栏与周期切换始终固定可见
- **修复窗口较小时收益记录无法查看** - 此前窗口高度不足时记录列表会被压缩到完全看不见。现在列表始终保留可读空间，内容随页面滚动查看
- **修复稀有掉落统计、试炼翻牌统计底部内容看不到** - 此前两页内容超出窗口高度时没有任何滚动条，底部内容无法到达。现在整页统一滚动，所有内容均可查看
- **修复账号管理页低窗口下的滚动问题** - 分区布局在窗口较小时也能滚动到全部内容
- **修复设置弹窗尺寸跳动** - 弹窗尺寸固定并适配小屏，切换分类时不再忽大忽小
- **修复散件清单材料数量严重偏少** - 此前按交易次数统计且去重窗口会误丢同屏多笔到账（实测一晚茶饼 6 个只记 1 个）。现在以购买消息确定种类，用前后 2 秒内的入包日志配对真实数量，多条到账累加，无到账日志时按 1 笔回退
- **修复材料估价系统性偏高** - 此前取价接口实际返回挂单快照而非成交数据（实测茶饼估 555 金而真实成交约 300 金）。现改用成交聚合接口取前一天成交量加权均价，与游戏内成交流水一致
- **修复装备估价虚高约一万倍** - 扫描器此前把 NPC 收购价（单位铜）误当作金入库，170 金被记成 170 万金。现按 1 金 = 10000 铜正确换算，历史记录在前端自动修正，重新扫描后彻底纠正
- **修复待确认记录编辑弹窗单价与总价不显示** - 兼容旧版字段命名，历史记录无需重新扫描即可正常显示每个单价与总估价
- **修复待确认列表估价与编辑弹窗不一致** - 列表金额改为按散件清单实时重算，口径统一
- **新赛季自动刷新装备价格缓存** - 游戏版本调整装备价格后，扫描检测到缓存属于旧赛季会自动清除并重取最新价格
- **添加副本记录弹窗体验优化** - 布局更紧凑；散件清单跟随弹窗统一滚动不再出现双滚动条；打开弹窗时背景页面不再跟着滚动
- **散件老板默认勾选与清单分组** - 扫描识别出散件清单时自动勾选「散件老板」；清单按材料 / 装备两组显示并附小组小计，长清单核对更轻松
