# JX3 Raid Manager（剑网三副本管家）

> 一款为《剑网3》团长与多号玩家打造的本地化团队管理工具，集中解决副本收入记录、账号角色管理、掉落统计、BOSS CD 追踪等日常痛点。

![JX3 Raid Manager 预览图](https://cdn.jx3box.com/upload/post/2026/2/24/29953_1557557.png)

## ✨ 核心功能

- **💰 智能工资结算** - 记录团队副本、百战、试炼之地等玩法的收入与支出，支持备注、明细查看与汇总统计
- **📊 数据概览更清晰** - 首页支持按时间范围查看收益、记录数、稀有掉落等关键数据
- **👥 账号与角色统一管理** - 支持手动添加或扫描游戏目录自动识别本地账号，支持本人/代清分类管理
- **↕️ 账号拖动排序** - 账号管理页支持直接拖动账号栏调整显示顺序，排序结果自动保存
- **🔍 角色搜索与筛选** - 团队副本、百战、试炼之地都支持按角色名、区服、账号快速搜索
- **🗡️ BOSS CD 追踪** - 25 人团队副本 BOSS 击杀状态记录与 CD 展示
- **🎁 稀有掉落统计** - 玄晶、马具、宠物、挂件、坐骑、外观、称号、秘籍等特殊掉落统计，支持按掉落类型多选筛选
- **⚔️ 百战/试炼之地支持** - 除团队副本外，也支持百战与试炼之地的数据管理
- **🌙 本地化存储** - 所有数据默认保存在本地设备，安装版支持应用内自动更新

## 🚀 快速上手

### 1. 下载客户端

前往 [GitHub Releases](https://github.com/lesswhite810/jx3-raid-manager/releases) 下载最新版：

- **安装版** - 支持应用内自动更新，适合长期使用
- **便携版** - 免安装，适合随身携带或手动备份

### 2. 配置游戏目录

启动应用后，在配置页填写《剑网3》游戏目录（例如 `E:\Game\SeasunGame`），程序会自动补全到正确的游戏数据目录。

### 3. 添加或扫描账号

进入"账号管理"页面后，你可以：

- 点击"**角色分析**"自动扫描游戏目录，导入本地账号与角色
- 点击"**新增账号**"手动添加账号，再在账号下添加角色

### 4. 开始记录副本数据

进入对应玩法页面后，点击"添加记录"，选择角色、副本、难度，输入工资收入即可。

### v2.2.11（2026-11-14）

- **试炼之地进行中提示** - 正在打但还没打完的试炼，此前完全没有任何提示，容易以为没识别到；现在扫描按钮旁会显示「试炼之地·第N层第M关·进行中」徽标（多个角色同时进行时显示角色数量），打完出现终局后自动转为正常记录。徽标只在确实还在打时显示：停止试炼超过约 45 分钟、角色离线、或转去打了其他副本后自动消失；跨天续打同一层（比如周一打完老一、周五继续打老二老三）也能接上之前的进度，老一不会被漏记。
- **修复试炼之地跨天续打丢关卡** - 同一层的关卡分两天打时（今天打完第一关，明天再进副本接着打第二关和第三关），此前这条记录会变成「第1关待确认」，第一个首领显示成待确认、翻牌次数也对不上；现在两天打的分关能接成一条完整记录。重新扫描一次本周即可补回此前被拆散的记录。
- **「扫描本周」明显变快** - 账号多、本周打得多的号，此前点一次「扫描本周」要干等半分钟以上，时间主要花在反复翻查每个角色的聊天记录来确认哪些场次真的击杀成功；现在同样的聊天记录只查一次、且只打开真正覆盖该场次时间段的那一个，跳过的无效查询占了绝大多数，等待时间大幅缩短。
- **「扫描本周」再快一截** - 同一份战斗日志此前一轮扫描要反复读三四遍（确认击杀读一次、核对结算再读一次、找战斗结束时间又读一次），打得多的号光重复读盘就要几十秒；现在一份日志只解析一次，后续判断都复用同一份结果。此外，本周已经用手工记录登记过的副本会在一开始就跳过，不再白算一遍补强、最后又被丢弃。
- **修复自动识别记录一直显示「扫描中」** - 关掉游戏后，之前还没确认的自动记录会一直卡在「扫描中」、按钮点不动，而且游戏不开就永远不会自己恢复；现在应用启动或点「扫描本周」时会自动把这类记录转成待确认，你可以直接确认或拒绝。
- **日志文件不再被无用信息刷屏** - 此前每次扫描会为每一场战斗写好几行内部诊断，日志很快涨到几百 MB；现在这些信息默认不再写入，需要排查时可以用环境变量 `JX3_LOG_LEVEL=debug` 临时打开。
- **非满级角色不再参与「扫描本周」** - 角色多的账号此前每次扫描都要把练级小号和旧赛季遗留角色一起扫一遍，白白拖慢速度；现在扫描只处理当前版本满级的角色，其余角色自动跳过，扫描进度里会写明保留几个、跳过几个。
- **「本周团队秘境」获取失败提示不再出现** - 剑网3魔盒接口调整了返回格式，导致打开应用时提示「本周团队秘境获取失败」、CD 概览里看不到本周团队秘境一栏；现在已适配新格式，本周团队秘境名单恢复正常显示。

### v2.2.10（2026-11-10）

- **CD 概览支持按心法和账号筛选** - CD 概览表新增心法、账号两个筛选下拉，下拉里只列出当前实际存在的心法与账号；筛选后角色名前显示职业图标，筛选条件可一键清除。
- **CD 概览可选择是否展示历史赛季周常** - 设置「界面」新增「展示周常」开关：开启保持现状（全部周常都显示），关闭后只显示当前赛季副本，历史赛季周常不再占用列宽（收藏的历史赛季副本仍出现在收藏列）。
- **试炼之地简化装备确认流程** - 试炼记录不再有「确认本轮无装备」「已核对全部牌面」两个待确认状态：翻牌时选了哪个牌位、牌上有没有装备，记录里直接呈现，概率统计改用已确认牌位的记录，结果不受影响。补录翻牌必须先选择翻到的牌位才能保存，未获得装备的翻牌不用填写任何装备信息。
- **副本管理可切换新版与旧版** - 设置里新增「副本管理」选项。默认的新版进入副本管理就是 CD 概览表；切成旧版后恢复以前的样子，顶部重新出现「团队副本 / 试炼之地 / 百战」页签，团队副本页展示本周团队秘境与收藏副本卡片，角色卡片上也重新带回账号与密码的显示与复制。
- **系统配置分类更清晰** - 原来「游戏配置」与「自定义配置」两个分类里混着游戏设置和应用自身行为，看不出该去哪找；现在合并为一个「游戏与应用」页面，内部按「游戏 / 应用行为 / 界面 / 数据与维护」四段分组，每组有标题和分隔，一眼看出某个开关属于哪一类。
- **副本管理可自动隐藏非满级角色** - 设置「界面」新增「自动隐藏非满级角色」开关（默认关闭）。开启后副本管理只显示已达当前版本满级的角色，练级中的小号不再出现；角色等级在「角色分析」扫描时自动识别，老角色重新扫描一次即可补上。等级未知的角色仍正常显示，不会被误隐藏。
- **无底薪公告的单笔工资自动入账** - 团长没发「每人底薪」结算公告时，此前整金工资到账会标记为「N 笔收入待核对」需手动确认；现在最后一战之后聊天里只有一笔整金入账时自动计入收入，不再弹出待核对。带银铜零钱的拾取或多笔入账仍保留待核对，避免误算。
- **修复试炼翻牌截图在聊天日志迟到时丢失** - 聊天插件落盘延迟超过 15 分钟时，此前截图识别会因内存帧被清理而失效；现在识别结果先持久化保存，日志晚到也能自动补录（最多支持 2 小时内的迟到回执）。
- **修复删除过的试炼记录无法重新扫描** - 手动删除试炼记录后，此前再点「扫描本周」也不会重新扫出同一条记录；现在手动扫描会重新导入已删除的记录及其翻牌明细，后台自动扫描仍不打扰已删除的记录。
- **修复试炼之地跨周无法补扫** - 打试炼之地时没开应用，此前「扫描本周」只能识别本周一之后落盘的记录；现在离线补扫范围放宽到上一个游戏周，上周打的试炼也能补进来。
- **修复自动试炼记录无法补录翻牌** - 自动识别的试炼记录没找到翻牌明细时，此前没有补录入口；现在记录列表提示「补录翻牌」，点开后可在编辑弹窗直接补记每次翻牌的牌位与装备，补录结果同样计入概率统计。已有日志明细的记录仍保持逐笔修改方式。
- **修复带服务器后缀的角色名无法自动扫描** - 茗伊装备库中名字带服务器后缀的角色（如「发白少·梦江南」）此前被误判为未登记而跳过扫描；现在会剥掉与服务器一致的后缀再匹配。
- **修复试炼之地「待确认」点开错的记录** - CD 概览里点试炼之地一列的「待确认」，此前打开的是团队副本的待确认记录，找不到要处理的试炼记录；现在会打开该角色的试炼记录列表，可直接在里面选中并确认。百战一列也一并核对，不会再错开团队副本的记录。
- **修复团队副本「待确认」展示全部记录** - CD 概览里点某角色某副本一列的「待确认」，此前弹窗列出所有角色所有副本的待确认记录，需要自己翻找；现在只显示该角色该副本的待确认记录，确认完即走。
- **修复待确认记录弹窗出现「(0)」空列表** - 从 CD 概览点「待确认」格子时，范围内已没有待处理记录会弹出显示「待确认记录 (0)」的空弹窗，确认完后弹窗也停留在这个空状态；现在范围内没有待确认记录时不再弹窗，确认完成后弹窗自动关闭。
- **修复末尾 BOSS 打完有剧情时漏记击杀** - 部分副本的最后一个 BOSS（如洛阳之战史朝义）打完还有一段剧情演出，结算奖励到达时间与以前判定用的"战斗结束"对不上，导致整场漏记击杀、工资算少；现在改用对 BOSS 的最后一次伤害作为识别起点，该类场次能正确补记击杀。

- **修复装回旧版本无提示** - 检测到数据来自更新的版本时会明确提示，并说明翻牌明细与已删记录的影响。
- **修复升级前的数据检查不完整** - 升级前会检查数据是否完整，发现异常直接提示并停止。
- **修复切换游戏目录互相干扰** - 切换游戏目录时不再与自动扫描、试炼截图识别冲突。
- **修复试炼翻牌确认失败无反馈** - 确认时牌面已被改动会明确提示，不再点了没反应。
- **修复试炼卡片待确认色常驻** - 卡片颜色只看本周的待确认记录，历史遗留记录不再影响显示。
- **统一试炼与百战卡片状态配色** - 未清绿、部分完成蓝、待确认棕、已打完灰，四种状态一眼可分。

- **修复团队副本卡片渐变底色** - 卡片改为单色，与整体扁平风格一致。
- **修复团队副本按钮深色主题不可读** - 按钮配色跟随主题，深色主题下文字清晰可辨。
- **修复添加记录按钮文字偏淡** - 「添加记录」按钮底色加深，浅色主题下文字更清晰。
- **统一三个副本模块的卡片与按钮样式** - 团队副本、试炼之地、百战的卡片与按钮配色、悬停效果保持完全一致。
- **修复深色主题下下拉框文字看不清** - 所有下拉列表与选择框跟随主题配色，深色下为深底浅字。
- **修复深色主题下记录日期弹窗时间白底** - 记录日期的时间列表、日期面板与「今天」按钮跟随主题底色。

- **统一弹窗遮罩与描边** - 各页面弹窗遮罩统一跟随主题，弹窗边缘补齐细描边。
