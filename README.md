# JX3 Raid Manager（剑网三副本管家）

> 一款为《剑网3》团长与多号玩家打造的本地化团队管理工具，集中解决副本收入记录、账号角色管理、掉落统计、BOSS CD 追踪等日常痛点。

![JX3 Raid Manager 预览图](https://cdn.jx3box.com/upload/post/2026/2/24/29953_1557557.png)

## ✨ 核心功能

- **💰 智能工资结算** - 记录团队副本、百战、试炼之地等玩法的收入与支出，支持备注、明细查看与汇总统计
- **📊 数据概览更清晰** - 首页支持按时间范围查看收益、记录数、稀有掉落等关键数据
- **👥 账号与角色统一管理** - 支持手动添加或扫描游戏目录自动识别本地账号，支持本人/代清分类管理
- **↕️ 账号拖动排序** - 账号管理页支持直接拖动账号栏调整显示顺序，排序结果自动保存
- **🔍 角色搜索与筛选** - 团队副本、百战、试炼之地都支持按角色名、区服、账号快速搜索
- **🗡️ BOSS CD 追踪** - 25 人团队副本 BOSS 击杀状态记录与 CD 展示
- **🎁 稀有掉落统计** - 玄晶、马具、宠物、挂件、坐骑、外观、称号、秘籍等特殊掉落统计，支持按掉落类型多选筛选
- **⚔️ 百战/试炼之地支持** - 除团队副本外，也支持百战与试炼之地的数据管理
- **🌙 本地化存储** - 所有数据默认保存在本地设备，安装版支持应用内自动更新

## 🚀 快速上手

### 1. 下载客户端

前往 [GitHub Releases](https://github.com/lesswhite810/jx3-raid-manager/releases) 下载最新版：

- **安装版** - 支持应用内自动更新，适合长期使用
- **便携版** - 免安装，适合随身携带或手动备份

### 2. 配置游戏目录

启动应用后，在配置页填写《剑网3》游戏目录（例如 `E:\Game\SeasunGame`），程序会自动补全到正确的游戏数据目录。

### 3. 添加或扫描账号

进入"账号管理"页面后，你可以：

- 点击"**角色分析**"自动扫描游戏目录，导入本地账号与角色
- 点击"**新增账号**"手动添加账号，再在账号下添加角色

### 4. 开始记录副本数据

进入对应玩法页面后，点击"添加记录"，选择角色、副本、难度，输入工资收入即可。

## 📋 更新日志

### v2.2.7（开发中）

- **核对副本收入** - 待确认记录提供有歧义的入账候选，展示发生时间和原始金额，可选择属于该场副本的收入；首领击杀识别补充结算证据不足的诊断信息。
- **显示本周团队周常** - 启动时获取周常名单，在副本收藏中展示对应的 10 人难度；已收藏的副本不重复显示，周常不会自动变成固定收藏。
- **简化试炼录入** - 移除重复的翻牌位说明，明确区分新增与编辑；历史翻牌保留并回显原有牌位。
- **优化试炼装备补录** - 牌位选择固定显示，核对与完成按钮集中排列；装备选择使用单一滚动区域，保留勾选筛选。
- **调整试炼记录与补录** - 待确认记录以卡片颜色区分；隐藏常规奖励，并在自动记录中使用与手工记录一致的装备选择弹窗。
- **完善试炼翻牌补录** - 手工和自动记录共用装备选择器，支持输入品级和按部位、属性筛选；牌位可再次点击取消，未知牌位或未核对牌面显示待确认，已核对的自动翻牌可折叠。
- **按翻牌展示本周进度** - 角色卡按每次翻牌的实际时间计数，一轮多次翻牌分别统计；银叶子与九花玉露散和其他翻牌奖励分开展示。
- **优化试炼记录详情** - 调整通关记录和逐次翻牌的展示布局，让牌位、奖励与精力消耗更容易查看；操作按钮集中在记录头部，翻牌明细充分利用记录宽度。
- **统一试炼详情配色** - 按完成、待确认和删除等状态统一文字与按钮颜色，改善不同主题下的辨识度。
- **逐次补录试炼装备** - 连续翻牌时可分别为每次翻牌的牌位选择或清除装备；未观察的牌继续显示待核对，手动补录不会影响其他翻牌。
- **优化试炼补录筛选** - 统一详情中的补录按钮尺寸，为逐次装备补录提供品级、部位、绑定和属性筛选，并区分通关信息与翻牌明细入口。
- **手工记录多次翻牌** - 同一轮通关可逐次填写和编辑翻牌，未记录的翻牌时间、奖励与精力保持未知；手工明细与自动日志可能重叠时提示核对，避免重复统计。
- **试炼之地自动记录** - 开启自动扫描后，从茗伊战斗记录识别每轮通关的角色、层数和三关首领。缺少关卡信息时可在角色详情中确认，翻牌位置与装备可稍后补录。未补录的牌位不参与翻牌统计。
- **同一轮连续翻牌** - 一次通关只计一次进度。角色详情按次列出翻牌时间、牌位、入包物品和精力消耗。账号精力与角色精力分开扣除时，按日志中的实际点数合计，并保留每笔扣减。牌位未知时可单独补录。关闭截图识别也能从日志读取奖励和精力，历史记录可用「扫描本周」补扫。
- **降低试炼识别开销** - 第三关最终通关后才启动截图，结算面板出现后自动加快采样，翻牌动画期间保持观察。截图缓冲复用，装备文字识别独立执行且不积压任务，日志增量读取和缓存都有上限。后台识别使用较低线程优先级，处理较慢时主动降低采样频率，使用实际取帧时间关联奖励。连续翻牌按新牌面分别关联，避免上一张牌的残留金框或装备提示影响下一次。
- **收紧试炼截图范围** - 第一、二关、战斗和跨天保存进度不启动截图，历史进度只用于关联同一轮记录。最终通关后，只有唯一活跃角色的近期通关才能启动采集。通关日志由轻量快速通道及时发现，首次最多等待约 2 秒让选择器出现；见过选择器后确认关闭便立即停止。有效画面不确定时仅短暂复核约 1 秒。翻牌动画中仍存在的结算标题栏和底部按钮用于避免误停。游戏进程退出或被替换时直接停止，不等待日志轮询。同一轮迟到奖励只关联已有识别结果，不会再启动截图。通关日志尚未被扫描到就已关闭的牌面保持未知，奖励与精力仍从日志记录。
- **试炼截图识别（默认关闭）** - 在「设置 → 游戏配置」同时开启「自动扫描」和「试炼截图识别」。结算时保持五张牌的底边可见，鼠标停在想查看的装备图标上，让提示框展开。助手通过选中金框和本人入包记录确定翻牌位，用本机中文 OCR 读取奖励装备，并将目录中唯一匹配的装备填入鼠标所在的牌。查看其他牌或对比当前穿戴装备不会改变已翻牌位。未知装备可在角色详情补录。截图仅在内存中处理，开关会保存到本机。截图识别支持最多 4K 像素数；超出时仍可从日志记录通关、奖励和精力。
- **试炼存档续打** - 同一游戏周内，凌晨过关保存、晚上或次日继续挑战时，可根据保存进度补齐同一轮的首领顺序。已有待确认记录可点击「扫描本周」重新识别。
- **支持侠行点辅助识别首领击杀** - 首领本体的有效伤害已覆盖全部血量时，同角色在战斗结束前后 15 秒内实际获得的侠行点（例如 150 点）也可补记击杀。奖励时间同时靠近两场战斗时会跳过。
- **修复洛阳之战首领进度漏记** - 阿史那承庆可通过「垂天浮屠宝箱」识别。10 人和 25 人普通史朝义缺少死亡记录时，可结合本场战斗、本人结算奖励与对应首领的物品记录补记。10 人本也支持宝藏结算后直接发给本人的物品。
- **修复手动更正首领进度后 CD 未更新** - 在待确认记录中勾选或取消首领后，副本进度与角色的首领 CD 会一同更新。
- **修复试炼装备部位筛选** - 根据当前赛季实际加载的装备显示部位选项，苍生铸世只显示项链和暗器，不再显示帽子、鞋子、腰坠等无对应装备的选项

- **修复 Gitee 源码镜像同步** - 发布后同步最新主分支和标签，并提供独立补同步流程，避免源码镜像遗漏更新

### v2.2.4（2026-10-31）

- **新增最小化到托盘** - 点击最小化按钮可收进系统托盘并在后台运行；点击图标或选择“恢复主窗口”即可返回，也可通过托盘菜单“退出应用”完全退出
- **避免重复启动多个窗口** - 重复启动时会恢复并聚焦已打开的窗口，不会重复初始化
- **修复试炼层数跨等级沿用** - 新游戏大版本没有该角色试炼记录时，默认从第 1 层开始；已有记录时沿用该大版本的进度，同一大版本换赛季不重置
- **更新当前赛季试炼装备范围** - 苍生铸世默认最低品级更新为 900 品，上限按实际装备数据确定
- **改进副本击杀记录识别** - 结合战斗和结算记录补齐部分遗漏；结算记录不完整时，不会撤销已有可靠证据确认的击杀
- **修复合并副本日志时误记击杀** - 合并日志时不再仅凭首领名称差异、最后一份日志或日志顺序补记击杀
- **修复部分首领宝箱未识别** - 可匹配名称含点号的首领宝箱；旧扫描缓存会在下次扫描时重新计算

### v2.2.3（2026-10-31）

- **新增苍生铸世赛季** - 新增 50 级「洛阳之战」，支持 10 人普通、25 人普通、25 人英雄，启动时自动补入预置配置
- **洛阳之战 BOSS CD 追踪** - 按 5 个正式 BOSS 追踪，伊曼·逐焰作为伊曼·寂夜的分身共用 CD
- **新赛季试炼装备自动同步** - 未预置品级范围时同步全部无修装备，装备选择器按实际数据生成品级区间，同步失败保留已有装备，不会清空
- **修复副本结算归属** - 连续进入两个副本时，前一个副本及时结束，掉落和工资按副本切换时间分别归属，避免重复计入
- **修复部分界面底色与描边不显示** - 恢复收益概览、记录详情、待确认记录等模块的淡色样式，并统一主题名称与跨角色同步配色
- **修复全新安装后跨角色同步回滚失效** - 全新安装的数据库缺少回滚标记表，导致跨角色设置同步后无法回滚；升级安装不受影响，本次已补齐
- **修复删除账号目录可能删错位置** - 删除账号 / 角色目录时会先校验目标确实位于已配置的游戏目录内，路径异常时拒绝删除并提示，不再可能误删其他文件夹
- **修复自动保存可能清空账号与副本** - 数据读取失败时自动保存可能把账号 / 副本列表当成空数据写回，导致数据丢失；现在自动保存只增改不删，只有用户主动删除才会真正删除
- **修复试炼自动填充开关在部分情况下不保存** - 该开关此前绕开主配置独立写库，可能与主配置互相覆盖；现在统一走同一保存路径
- **修复添加副本记录弹窗顶部两栏高低不齐** - 记录日期与「击败 BOSS」并排时，BOSS 名称过多换行会把右侧撑高、日期框却仍是单行高度；现改为上下两行各占满整行宽度，BOSS 较多时也不再出现错位
